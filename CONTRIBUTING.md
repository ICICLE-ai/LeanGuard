# Contributing

The original repository for this project is [`DebarghaG/LeanGuard`](https://github.com/DebarghaG/LeanGuard). The ICICLE fork tracks its `main` branch.

- Submit changes to the project through [upstream pull requests](https://github.com/DebarghaG/LeanGuard/pulls).
- Report bugs and request project features through [upstream issues](https://github.com/DebarghaG/LeanGuard/issues).
- For changes to the ICICLE catalog metadata or the fork's CI and sync workflows, open a pull request in the [ICICLE fork](https://github.com/ICICLE-ai/LeanGuard/pulls).
